# Portafolio Personal - Bootstrap 5

## Objetivo
Página de presentación personal desarrollada con Bootstrap 5 y CSS propio,
aplicando HTML5 semántico y diseño responsive.

## Cómo ejecutar
1. Clonar el repositorio.
2. Abrir el archivo index.html en el navegador.
No requiere instalación adicional, ya que Bootstrap se carga vía CDN.

## Componentes de Bootstrap utilizados
- Navbar responsive (navbar-expand-lg)
- Grid system (container, row, col)
- Cards
- List Group
- Badges / Rounded Pills

## Personalización con CSS
- Variables CSS para color de acento y tipografía
- Sombra y transición en foto de perfil y cards
- Especificidad usada en lugar de !important para sobreescribir la navbar
